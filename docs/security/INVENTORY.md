## Compatibilidade, licenças e limites

Core MIT; Avataaars código MIT/design PabloStanley livre pessoal/comercial, sem alteração de licença9.4.3. Firebase/Admin/Google/grpc Apache2; uuid MIT. Node24 satisfaz engines; sem serviços pagos/telemetria nova.

Overrides, se adotados, não tornam ranges upstream compatíveis magicamente. Serão exatos/limitados e terão provas de require/v4+HTTP multipart e cliente Firestore/gRPC emulado, árvore válida e lockfile/install limpo. Emuladores não certificam TLS/gRPC em produção; ausência de caminho de exploit observada não é prova absoluta contra futuras configurações. Sem testes live/chaves/admin production. Remover/reavaliar overrides quando upstream publicar ranges corrigidos; nunca forçar uuid12+/Gax5/Firestore8 no escopo atual.
