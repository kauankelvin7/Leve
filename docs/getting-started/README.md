# Começar

O [README principal](../../README.md) apresenta o Leve e inicia a aplicação local com Node.js 24.x, npm 11.19.1 e `npm run dev`. Esse comando inicia a web, a API e os emuladores locais. Use `npm run seed:local` em outro terminal para criar dados fictícios.
